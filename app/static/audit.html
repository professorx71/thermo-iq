Audit PDF Report

Select a logger and calendar date. The report includes daily min/max/average, alarm count, downtime, calibration reference, acknowledgement, and corrective action.

Record integrity: each PDF contains a SHA-256 hash of the underlying report dataset. PDF modification is restricted; this is not a cryptographic digital signature.
Calibration Record

Document reference instrument, offsets, calibration date, next due date and technician. Saving the record applies the documented offsets to the live logger. A reminder email goes out before each next-due date (Settings → Email reports).

Alarm Deviation & Corrective Action

Attach maintenance/QA action to a recorded temperature alarm episode so the audit report shows what happened and what was done.

Retention & Backup

Local audit, alarm and downtime records can be retained for 1–3 years. Automated backups contain data/configuration JSON only; secret credentials in .env are intentionally excluded.

Recovery: the backup ZIP contains alarm events, acknowledgement state, logger settings, downtime history, calibration records, deviations, audit trail and report settings. Keep a separate protected backup of the server .env credentials.
